# ADR-0002: Fuente y contexto juntos, controles locales y en GitHub

- Fecha: 2026-10-03
- Estado: aceptada para la base de colaboración
- Autor: Codex; operador: soyabrahamarriaga-lang
- Evidencia: solicitud del usuario de verificar que se suban código y archivos de texto.

## Decisión y razón
Interpretar la solicitud como versionar código fuente y contexto textual juntos. Se aceptan archivos UTF-8 de hasta 1 MiB, incluidos configuraciones y lockfiles; se rechazan binarios, enlaces, submódulos, punteros LFS, dependencias, builds y archivos de credenciales conocidos. Si más adelante se necesitan recursos multimedia, se decidirá explícitamente dónde alojarlos y cómo versionar su manifest.

El pre-commit lee el índice de Git, no archivos de trabajo posiblemente distintos. Exige una entrada nueva que cubra los archivos modificados. El pre-push comprueba que no queden archivos pendientes y revisa los commits. GitHub Actions valida commits intermedios y resultado final. `main` se configura para exigir PR, base actualizada y `context-integrity`, también para administradores, sin force push ni borrado.

## Alternativas y límites
Un checklist sin ejecución no detecta omisiones. Solo hooks no protege otras computadoras. Solo CI detecta problemas después del push. La combinación reduce errores, pero no evita que un usuario omita sus hooks y suba una rama inválida: lo que bloquea GitHub es su integración a `main`.

No se puede garantizar que un archivo ignorado intencionalmente sea innecesario, ni que una decisión nunca expresada figure en la memoria. No se implementa un detector universal de secretos. No se exigen aprobaciones de otra cuenta mientras solo exista un operador confirmado; el PR y sus checks sí son obligatorios.

## Impacto ontológico y verificación
Una revisión técnica no equivale a una prueba de transferencia de conocimiento del producto. La prueba del harness usa repositorios temporales y casos negativos para omisiones, binarios, historia y referencias rotas. Los resultados concretos se registran en la bitácora.
